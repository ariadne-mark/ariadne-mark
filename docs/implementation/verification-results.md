# Разделить результаты проверки и ошибки

Требование: **REQ-008**. Статус: **запланировано**.

## Критерий приёмки

Различать not_found, not_checked, invalid и verified_claim; unsupported format и отсутствующие модели не превращаются в «метки нет». Неподписанный результат не получает статус trusted.

## Расположение

- Реализация: `src/ariadne_mark/verification/`
- Проверки: `tests/verification/`

## Доказательство

В Ariadne Mark пока не реализовано и не проверено. После реализации здесь будут пример использования, поддерживаемые версии и ограничения.
