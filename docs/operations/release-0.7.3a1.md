# 0.7.3a1 candidate: verifier integrity and migration

This unpublished candidate follows the independently reviewed 0.7.3a0. It is
not legal certification. All marking profiles, schedules, strength, models and
direct-SDK Economy5s default remain unchanged.

Untrusted/development signatures cannot suppress configured independent scans.
A signed Python-Q video claim requires its historical decoder without removing
the primary check. Current video negatives cover video-Q, not the supplemental
legacy Python-Q decoder. `all` retains the wider legacy obligations.

The content resolver refuses out-of-scope queries and distinguishes incomplete
search from a completed empty result. Signed-ID observation is tri-state; UI
first/last reads do not assert a continuous interval. Untrusted issuer headlines
disclose incomplete watermark checking.

Bare model commands auto-select the available current runtime; explicit media
selection stays strict. Legacy kits warn on missing configured models and need
a conscious compatibility-preserving migration. See [CLI and scope contract](../reference/api-cli.md#detection-scope-and-model-selection).

Active candidate docs are updated; dated baseline measurements and source reviews
remain attributed to their original release. Final exact-SHA CI, kit acceptance
and artifact hashes must accompany distribution; editing this note does not make
a previous failed CI green. Mode-specific legal sufficiency, broad representative
robustness, crop/remover limits and production trust/TSA remain separately scoped.
