# Ariadne Mark 0.7.3a3 candidate

This candidate retains the 0.7.3a2 verifier, installation and shared-worker
changes, and completes the optional authenticated TSA route. It is not a
published release. Exact-version acceptance results are recorded separately;
older 0.7.2a1/0.7.3a1 measurements remain historical.

See [authenticated timestamping](authenticated-timestamping.md),
[production onboarding](production-onboarding.md) and
[the previous candidate](release-0.7.3a2.md).

Economy5s default, Economy2s and Resilient schedules and payload formats are
unchanged. A mode is not a legal certification, and successful offline signing
does not establish real CA enrollment or live TSA qualification.
