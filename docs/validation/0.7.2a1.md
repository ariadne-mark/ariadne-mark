# 0.7.2a1 qualification protocol

Follow-up to the independent 0.7.2a0 review, on the same Linux x86-64 CPU scope.
No marking profile, model, payload, cadence, default, strength or runtime pin is
changed. Historical speed/durability results are not relabelled as this version.

New regressions cover future timestamp issuance (including batch all-or-nothing
preflight and direct signing), external-claim parsing, provider path/EKU
validation (valid signer purposes, wrong roots/signatures, missing intermediate,
CA constraints, expiration and restricted purposes), one-version kit policy,
audio mismatch preflight, incomplete-result headlines and California date fields.
The six-second install/kit fixture checks distinct Economy5s/Economy2s schedules
and Resilient per-frame marking, in addition to the existing signed-report,
external c2patool, metadata-removal recovery and key/registry isolation tests.

All tests run on EC2. Final counts, exact source SHA, wheel/sdist hashes and CI
URL are recorded only after completion in the release manifest and output logs.
Production certificate enrollment/TSA/public TLS, uptime/accessibility and
population error-rate qualification remain outside this developer alpha.
Recovery acceptance covers metadata removal without re-encoding. The known
full-range 4:4:4 chroma offset remains documented; no color pipeline fix or new
robustness claim is made here.
