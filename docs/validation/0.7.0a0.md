# 0.7.0a0 — signed reports and C2PA recovery

This candidate extends 0.6.0a0. Economy 5s remains the default; Economy 2s and
Resilient keep their marking cadence, payload format and decoder. No watermark
model or strength change is introduced.

| Change | Evidence / scope |
| --- | --- |
| Ed25519 compact-JWS verification receipts | Key substitution, result tampering, exact asset digest/size, independent key pinning, public-only response, separate verifier key, fail-closed signing |
| Local CLI report verification | No engine/network dependency; optional exact submitted-file check and expected verifier ID |
| Signed C2PA soft-binding assertion | Real binary value is checked as CBOR bstr, not merely JSON array; active manifest/ID must match final export |
| Exact manifest storage | Same SQLite transaction as provenance, immutable/idempotent binding, digest checking, rollback and old read-only database compatibility |
| Metadata-loss recovery | Blind ID decode, matching engine, signed original manifest retrieval; signature/trust and current-asset hard binding stay separate |
| Public read-only recovery API | Standard byBinding GET/POST, byContent upload, supportedAlgorithms and full manifest fetch; publication requires explicit opt-in |
| Native C2PA patch update | Official 0.91.11 fixes upstream JSON→CBOR byte typing; archive/library SHA-256 pinned; bootstrap force-reinstalls same Python version to replace native bytes |

Reports do not create a legal verdict or establish factual truth. Verification
clock timestamps are not TSA attestations. Public keys must be pinned through a
trusted channel. Production issuer certificates/trust/TSA and operational
availability still require operator qualification.

The API is a documented read-only subset of C2PA 2.4 soft-binding resolution.
Provisional `org.ariadne-mark.*` algorithms are not enrolled in the official
algorithm list. Global discovery, conformance certification, active-only fetch,
reference URL fetching, repository receipts and public write routes are not
claimed. Full manifests can include inherited personal/free-text data; explicit
publication must follow review. Existing compact public-response redaction is
retained.

Known Economy temporal-window removal behavior and limited population/FPR
calibration remain as recorded for 0.6.0a0. These features do not change that
robustness evidence or make Economy a certified compliance preset. Synthetic
soundtrack marking remains outside the visual SDK's qualified scope.

See [signed reports](../operations/signed-reports.md) and
[C2PA recovery](../operations/c2pa-recovery.md) for configuration and limits.
Exact installed-wheel Linux qualification and downloadable fixture evidence
are recorded in the release evidence directory; they are distinct from local
unit tests that skip media engines.
