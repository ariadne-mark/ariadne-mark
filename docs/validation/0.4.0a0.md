# Validation — 0.4.0a0

Tested 2026-11-03. This release adds offline EU/California requirements profiles,
CLI configuration checking, and profile-bound image/video export receipts.
The watermark models and payload formats are unchanged from 0.3.0a0.

## Tests

- **61 tests passed** on the dedicated AWS m6a.large Linux x86-64 CPU host.
  The Docker container had 2 CPUs, a 6 GiB memory limit, read-only filesystem,
  temporary scratch storage and no network access. No GPU was used.
- The release wheel was installed without dependencies into an isolated target
  on the provisioned media image and tested with the same restrictions.
- The dependency-free installed-wheel suite also passed locally on Python 3.14:
  43 tests ran, with 18 media tests intentionally skipped. CI tests Python
  3.11–3.14 and independently builds/runs the full CPU media image.
- [Full media test log](results/media-tests-0.4.0a0.log).

The 16 new profile scenarios cover date boundaries, provider/deployer roles,
unknown scope, exceptions, California's amended provider definition, upload/URL
alternatives, third-party verification, strict parsing, stale source snapshots,
future schema gaps, configuration fingerprints and conflicting metadata.
Three new media tests cover CLI profiled image export, profiled VideoSeal video
export, and rejection of mismatched publisher information before publication.
The image test checks that the profile selects visible disclosure and that the
same assessment persists in the returned receipt, disk receipt and registry.

All previous image/video, signature, registry, verifier and fail-closed
regressions are retained. This release does not add new durability evidence;
the content/transform limitations from [0.3.0a0](0.3.0a0.md) continue to apply.

## Scope of the result

The tests verify the software's behavior against encoded scenarios. They do
not establish the legal correctness or sufficiency of a product deployment.
Profile `2026-11-03.1` records its sources and remaining actions. California's
chaptered text was reviewed via a mirror because the official endpoint returned
403; direct official consolidated-source reconciliation remains open. Complete
voluntary EU Code of Practice adherence is not assessed.

Public verifier availability, declarations, privacy, feedback, accessibility,
production credentials, durability/interoperability and exception assessments
require product-specific work. Standalone audio/text and independent synthetic
video-audio marking are not covered. No result is labelled legally compliant.
