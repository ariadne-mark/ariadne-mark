# 0.7.2a0 qualification protocol

This revision adds a deployment kit around the 0.7.1a2 SDK. TrustMark/ONNX model
weights, payload, strength, default Economy5s and Economy2s/Resilient policies
are unchanged. Earlier durability/remover evidence keeps its version/corpus
scope. It is not relabelled as a new population benchmark.

Release evidence must bind the final source commit to the installed wheel,
source archive, package parity and exact-SHA EC2 workflow. The workflow runs:

- the installed full-media suite and dependency-free Python matrix;
- clean media/video wheel installation and offline processing;
- kit initialization from the installed image, batch export of images and all
  three video modes, public HTTPS verification and detached-manifest recovery;
- signed report validation using an independently pinned key, persistence after
  container restart and read-only-registry/key-isolation checks;
- operator-config/profile failures and expected production credential gaps;
- requirement/lock consistency, inventories and archive hygiene.

The kit test uses isolated development credentials and local TLS with explicit
certificate pinning, not browser trust or real CA enrollment. Public DNS, an
operator's production identity/TSA and uptime are not supplied by this test.
Source/TLS trust, C2PA claims, recovered IDs and legal sufficiency stay distinct.
All SDK/runtime/media execution is on EC2. Exact counts/times and limitations
belong in the final CI artifact and release report, not predicted here.
