# 0.6.0a0 qualification scope

The release candidate combines configurable Economy/Resilient video, independent detection and a deployable verifier. Generated logs, hashes and dependency/model inventory identify the exact tested build; this document describes the scope rather than an evergreen passing claim.

## Encoder and export

- Three modes in one SDK: default `economy_5s`, optional `economy_2s`, per-frame `resilient`; explicit legacy Fast remains compatible.
- Fresh signal on selected PTS windows, with low-FPS/VFR occupied-period fallback. Unselected frames bypass watermark computation.
- Same input frames, audio packet bytes, VFR timestamps, duration and normalized orientation retained within the supported scope.
- Actual signed-file read-back: every occupied Economy window has a matching ID; Resilient/legacy sample gate retained. Partial marking and worker death publish neither output nor success receipt.
- Constructor, product JSON, CLI and per-export choices record the actual profile. Concurrent exports and worker reuse preserve IDs and avoid loading an unused default decoder.

## Verification and service

- Supported-scheme blind search, no expected ID/manifest/registry used to select an answer; cached-logit aggregate recovery without a second CNN pass.
- Conflicting IDs, a single unconfirmed observation, complete negatives and search-budget exhaustion remain distinct. Early positive detection is not whole-video coverage.
- Real signed/stripped media through the upload API and read-only operator resolver. API does not pretend an edited copy is cryptographically bound to a registry entry.
- Reviewed public system fields only; arbitrary/unknown metadata, debug output and unreviewed names are not reflected. A real signed private-name fixture checks the public boundary.
- Feedback counters accept only fixed category/media enums, reject extra text/contact fields, persist under concurrency and expose a read-only operator summary.
- Verification-only child deadline, descendant cleanup, restart after a failed job and HTTP 504/not_checked with upload cleanup.
- Packaged UI/assets/OpenAPI, request/body/header deadlines, temporary-file cleanup, busy handling and production trust-root validation.

## Evidence preceding this candidate

The Economy integration at commit `b9922174b335fd459620be7c551ebc386266ab99` passed 114 installed-package tests on Linux x86-64/2CPU and ten additional saved-asset positive/negative checks. The subsequent public-verifier/0.6 changes require their own installed-package run; do not relabel that earlier114-test result as evidence for later code.

The controlled four-fixture 10-second 720p24 performance experiment measured 8 exports per profile. Economy 5s/2s/1s used 6/15/30 encoder calls versus 240 for Resilient. Its private adapter timings are not the timing/SLA of every integrated SDK path.

On the ordinary-transform panel, each Economy candidate recovered 24/24 only after including slow aggregate recovery. A same-payload street-scene control showed 5s needing recovery where 2s confirmed directly. Four unique unmarked files produced no false candidate IDs in that experiment; this does not calibrate population false positives or the family-wise rate of phase-hypothesis search.

## Known adversarial limit

The separate known-cadence replacement stress retained duration/PTS while replacing scheduled frames with adjacent unmarked frames and re-encoding without metadata. On one matched street clip, Economy 5s lost its ID after 6/240 replacements; Economy 2s after 15/240. The same 6-frame transformation retained the Resilient control's ID. All observed results, including failures, are retained. This is relevant to durability claims; it is not a universal legal acceptance test or a guarantee that Resilient survives all attacks.

## Scope of a passing run

Passing tests establish the enumerated implementation behavior on the recorded environment. They do not establish universal media support, public endpoint availability, production trust enrollment, statutory permanence, full Code adherence or product-wide compliance. Review the [requirements map](../compliance/launch-mapping.md), [supported scope](../operations/support.md) and [deployment guide](../operations/verifier-quickstart.md).

Reproduction in the provisioned CPU image:

```sh
ARIADNE_MEDIA_TESTS=1 python -m unittest discover -s tests -t . -v
python scripts/check_requirements.py
```

Core-only runs intentionally skip real-media tests. Build/test a wheel with no source-tree import shortcut and record its SHA256 before distribution. A public combined Docker binary is a separate licensing/distribution boundary; this release supplies Ariadne's wheel/source and a Docker build recipe.
