# 0.7.1a2 — external-review fixes and qualification protocol

This revision addresses the 9 November 0.7.1a1 external review. Model weights,
payload, strength, phase bank, marking periods and default Economy 5s remain
unchanged. Existing [0.7.1a1 short/remover evidence](0.7.1a1.md) retains its
version/hardware scope; it is not relabelled as new testing.

- **N-01:** explicit encoder-compatible YUV420 bypass frames preserve full-range
  sample code values. Deprecated yuvj420p layout is copied with stride awareness;
  other chroma layouts use the explicit converter. No model inference or RGB
  round-trip on ordinary 4:2:0 bypass frames. Pixel/contrast tests cover selected
  and bypass frames, full/limited range, BT.601/709 and both Economy modes.
- **N-02:** installed-wheel `setup media` and `setup video`, packaged hash locks,
  unchanged verified C2PA bootstrap; unavailable wrapper removed from extras.
- **N-03:** reviewed-revision [server CI](../operations/server-ci.md), clean source
  build and isolated wheel installations. Exact results/hashes belong to the CI
  artifact `release-manifest.json` and logs, not a predicted static test count.
- **N-04:** current upstream-C2PA altered/composite semantics documented; a new
  relay action/source-type design remains deferred.
- **N-05:** CA planning adds explicit reviewed public-provenance configuration;
  verifier startup reports withheld fields. Privacy defaults remain unchanged.
- **N-06:** pure core construction is lazy; media calls, identity-bearing setup
  and HTTP startup retain qualification checks.
- **N-07:** format descriptors and actual frame formats reject non-8-bit input.
- **N-08:** a lone legacy video observation is not a confirmed recovered claim.
- **N-09:** production Node remains the evaluation path. The external reliability
  protocol and observations are archived with correct statistical scope; parity
  between different reference accumulators is not assumed.

See the [wheel setup guide](../operations/wheel-install.md),
[reliability protocol](../../benchmarks/reliability/README.md) and
[release gates](../operations/public-alpha-checklist.md). Source and runtime
inventories distinguish the SDK's own artifacts from a combined Docker binary.
No release tag, public hosted verifier or production issuer credentials are
supplied by qualification itself. No preset is a compliance certificate.
