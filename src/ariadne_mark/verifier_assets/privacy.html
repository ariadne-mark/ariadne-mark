↳ Ariadne MarkDATA HANDLING

A check, not a media archive.

Files selected for verification are uploaded to the server running this verifier. The application writes them to a random temporary directory, checks them, and deletes that directory before returning its response. It also removes temporary uploads when a request fails or times out.

What is returned

The public report contains credential status, supported watermark evidence and reviewed system provenance. Unreviewed free-text provider/model details and arbitrary embedded metadata are withheld. A local registry can map a public watermark ID to an operator-managed public provenance record. An ID match does not authenticate an edited copy.

What the application records

Default application logs do not retain IP addresses, original filenames or upload contents. The verifier has no account requirement, tracking scripts or analytics. If anonymous feedback is enabled, the application stores only aggregate counts for a fixed rating category and media type. It does not accept free text, contact details, media, IDs or individual feedback-event history.

What the operator controls

The hosting provider, reverse proxy, trust configuration, public-source list, registry and backups are controlled by this deployment’s operator. Their policies can differ from this reference application. A deployment should provide its own operator identity, privacy contact and retention information where applicable. Optional external feedback links are governed by the destination’s policies.
