# Security policy

## Current support status

Ariadne Mark is a pre-alpha scaffold. There are no supported production releases yet. Do not treat the repository as a production compliance or security service.

## Report a vulnerability

Use GitHub's private vulnerability reporting for this repository:

https://github.com/ariadne-mark/ariadne-mark/security/advisories/new

Include affected code/version, reproduction steps, expected impact, and a minimal non-sensitive example. Never attach real credentials, private user media, or personal data. Please keep exploitable details private while maintainers investigate.

The project is maintained on a best-effort basis; no response-time SLA is offered. Ordinary bugs and documentation corrections belong in Issues.
