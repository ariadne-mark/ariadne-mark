# Profile scenario tests

`test_profiles.py` checks date boundaries, provider/deployer separation,
unknown scope, declared exceptions, California amendment changes, verifier
submission alternatives, source freshness, unsupported audio, strict parsing,
CLI exit codes and record/configuration consistency.

Real-engine integration tests additionally export a profiled image and video,
check receipt persistence and reject a publisher mismatch before publication.
These validate software behavior; they do not establish legal sufficiency.
